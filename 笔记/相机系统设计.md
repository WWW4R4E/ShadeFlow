# 相机系统设计

## 相机的作用

相机在渲染引擎中扮演着至关重要的角色，它不仅是视角的提供者，更是连接3D世界和2D屏幕的桥梁。

### 核心功能

1. **视图变换**：控制相机在3D空间中的位置、旋转和朝向
2. **投影变换**：将3D场景投影到2D屏幕上
3. **相机控制**：提供用户交互方式来操作相机
4. **多相机支持**：在复杂场景中使用多个相机

## 相机类型

### 1. 透视相机 (Perspective Camera)
- 模拟人眼视角，具有近大远小的透视效果
- 适合大多数3D场景
- 参数：视野(FOV)、宽高比、近平面、远平面

### 2. 正交相机 (Orthographic Camera)
- 无透视效果，物体大小与距离无关
- 适合2D游戏、UI界面、工程设计软件
- 参数：视锥体大小、近平面、远平面

### 3. 轨道相机 (Orbit Camera)
- 围绕目标点旋转
- 适合展示3D模型
- 控制方式：鼠标拖动旋转，滚轮缩放

### 4. 第一人称相机 (First Person Camera)
- 模拟第一人称视角
- 适合第一人称游戏
- 控制方式：鼠标控制方向，键盘控制移动

### 5. 自由相机 (Free Camera)
- 完全自由的移动和旋转
- 适合场景漫游
- 控制方式：键盘控制移动，鼠标控制方向

## 相机数学基础

### 1. 视图矩阵 (View Matrix)

视图矩阵描述了相机在世界空间中的位置和朝向，它将世界坐标转换为相机空间坐标。

**计算方法**：
- 相机位置：`position`
- 相机目标：`target`
- 相机上方向：`up`

1. 计算相机的前向向量：`forward = normalize(target - position)`
2. 计算相机的右向向量：`right = normalize(cross(forward, up))`
3. 计算相机的上方向向量：`camera_up = cross(right, forward)`
4. 构建视图矩阵：
   ```
   [ right.x,  camera_up.x,  -forward.x,  -dot(right, position)  ]
   [ right.y,  camera_up.y,  -forward.y,  -dot(camera_up, position) ]
   [ right.z,  camera_up.z,  -forward.z,  -dot(forward, position) ]
   [ 0,        0,            0,           1                        ]
   ```

### 2. 投影矩阵 (Projection Matrix)

投影矩阵将相机空间中的3D点投影到2D屏幕上。

**透视投影矩阵计算**：
- 视野(FOV)：以弧度为单位
- 宽高比(aspect ratio)：width / height
- 近平面(near plane)：相机前方的最近距离
- 远平面(far plane)：相机前方的最远距离

```
[ x_scale,  0,          0,          0                            ]
[ 0,        y_scale,    0,          0                            ]
[ 0,        0,          z_scale,    z_offset                     ]
[ 0,        0,          -1,         0                            ]
```

其中：
- `y_scale = 1 / tan(FOV / 2)`
- `x_scale = y_scale / aspect_ratio`
- `z_scale = -(far + near) / (far - near)`
- `z_offset = (-2 * far * near) / (far - near)`

## 相机控制实现

### 1. 轨道控制

**实现步骤**：
1. 记录鼠标起始位置
2. 计算鼠标移动 delta
3. 根据 delta 计算旋转角度
4. 更新相机位置（围绕目标点）

**数学原理**：
- 使用球坐标系来表示相机位置
- 鼠标水平移动控制方位角(azimuth)
- 鼠标垂直移动控制仰角(elevation)

### 2. 平移控制

**实现步骤**：
1. 记录鼠标起始位置
2. 计算鼠标移动 delta
3. 计算平移向量（基于相机的右向和上方向）
4. 更新相机位置和目标点

### 3. 缩放控制

**实现步骤**：
1. 检测鼠标滚轮输入
2. 根据滚轮 delta 调整相机距离
3. 限制相机距离范围

## 相机系统设计最佳实践

### 1. 分离相机逻辑

将相机逻辑从引擎核心中分离出来，形成独立的相机类：
- 提高代码可维护性
- 便于功能扩展
- 支持多相机场景

### 2. 相机组件化

将相机设计为可组合的组件：
- 基础相机类提供核心功能
- 特定相机类型继承基础类
- 相机控制器处理用户输入

### 3. 性能优化

- 使用矩阵缓存，避免重复计算
- 只在必要时更新相机状态
- 考虑使用四元数处理旋转，避免万向锁问题

### 4. 相机参数调整

- 提供相机参数的运行时调整
- 支持相机预设（如正交、透视、第一人称等）
- 实现相机动画和过渡效果

## 总结

相机系统是渲染引擎的重要组成部分，它不仅决定了场景的呈现方式，还影响着用户的交互体验。一个设计良好的相机系统应该：

1. **功能完整**：支持多种相机类型和控制方式
2. **性能高效**：优化矩阵计算和状态更新
3. **易于扩展**：采用模块化设计，便于添加新功能
4. **用户友好**：提供直观的相机控制界面

通过合理的相机系统设计，可以大大提升3D应用的视觉效果和用户体验。
