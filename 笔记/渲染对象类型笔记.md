# 渲染对象类型笔记

## 两种渲染对象类型

### 1. RenderObject（普通渲染对象）
- 存储在 [render_objects](file:///c:%5CUsers%5C123%5CDesktop%5CShadeFlow%5CShadeFlowNative%5Csrc%5Cengine%5Ccore%5CEngine.zig#L207-L207) 数组中
- 只使用顶点缓冲区进行渲染
- 使用 `Draw` 方法进行绘制
- 适用于简单图形或不需要索引的几何体

### 2. IndexedRenderObject（索引渲染对象）
- 存储在 [indexed_render_objects](file:///c:%5CUsers%5C123%5CDesktop%5CShadeFlow%5CShadeFlowNative%5Csrc%5Cengine%5Ccore%5CEngine.zig#L208-L208) 数组中
- 同时使用顶点缓冲区和索引缓冲区进行渲染
- 使用 `DrawIndexed` 方法进行绘制
- 适用于复杂的几何体，可以减少重复顶点的数量，提高效率

## 不需要索引的图像类型

### 独立几何体
- **点精灵（Point Sprites）**：只由单独的点构成，每个点都是独立的，没有共享顶点
- **独立线段（Independent Lines）**：线段之间没有共享顶点的情况，如一些粒子效果中的线段
- **独立三角形（Triangle Lists）**：
  - 三角形之间没有任何公共顶点
  - 例如一些随机分布的三角形组成的特效
  - 粒子系统中的单个三角形面片

### 特殊效果
- **全屏四边形（Fullscreen Quad）**：虽然四边形通常由两个三角形组成（共4个顶点），但某些情况下可能不需要索引，直接使用4个独立的顶点
- **独立几何体**：如果绘制多个完全分离的简单形状，它们之间没有共享顶点
- **点精灵系统**
- **粒子系统**
- **星空效果**
- **某些UI元素**

## 需要索引的几何体类型

主要用于那些有大量共享顶点的几何体：
- 网格（Grids）
- 立方体（Cube）- 8个顶点表示12个三角形
- 球体（Sphere）
- 地形（Terrain）
- 模型网格（Model Meshes）

## 索引绘制的优势

索引绘制的主要优势是可以避免重复顶点数据，提高内存使用效率和渲染性能。
